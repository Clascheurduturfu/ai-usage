# 1.0-beta-2

Usage counters now distinguish actual API requests from repeated transcript records.

- Claude Code usage is deduplicated by API message identity. Thinking, text and tool blocks no longer multiply a request's token counts. Later usage updates merge without losing previously reported totals. Tool calls retain their own identities.
- Codex subtracts cached input and cache writes from inclusive input before displaying the token mix. Cumulative snapshots produce deltas; repeated snapshots do not add usage. Logs without ordinals retain distinct request and tool-call identities.
- Antigravity preserves its per-call session/sequence identity; repeated records update that call. Records without a sequence receive a content-based identity rather than sharing a single fallback ID. Separately reported reasoning is included once when required by the export's total. Conversation counts and quotas remain separate from token counts.
- Session and history views label mixed models explicitly. Claude totals show the main-conversation and subagent portions separately; exported history includes both portions.
- Verified Claude 5.5 prices take precedence over older family estimates. Haiku's 100K prompt threshold is applied per request, including cached input. One-hour cache writes and reported geography/fast-mode modifiers are retained when present. Exact user price overrides remain effective.
- Accessible indexed transcripts are automatically reparsed once for the corrected parser version. Subsequent scans remain incremental. Reindex reading is chunked to avoid retaining entire raw transcripts in memory.

Local token totals are activity measurements, not a fixed conversion to subscription allowance. Provider quota percentages remain the authority for subscription limits; API-equivalent cost estimates are not invoices. Third-party monthly allowance estimates depend on their workload and metering assumptions.

Validation uses synthetic parser, incremental-scan, aggregation, pricing and cross-provider regression fixtures, plus reconciliation against a private copy of existing local data. No prompts or account data are included in tests or packages. No paid inference or fresh OAuth consent is required.

Pricing references: [Anthropic](https://platform.claude.com/docs/en/about-claude/pricing), [OpenAI cached-token usage](https://developers.openai.com/api/docs/guides/prompt-caching).
