# AI Usage 1.0.0 RC 10

Release candidate for 1.0.0 fixing cross-device skill deletion during encrypted Sharing imports.

## Encrypted Sharing & Skills

- **Propagate deleted skills cleanly across devices**: [Sharing.import()](../../src/main/manager/sharing.ts) previously only wrote or updated files present in `bundle.skills`, leaving removed skills behind in `~/.agents/skills` (and outside updated `skillFolders`) on importing devices. Import now removes stale non-dot, non-symlink skill files absent from the incoming bundle with full rollback support, prunes empty directories, and lets the subsequent `SyncEngine.sync(true)` pass remove deleted skills from downstream agent folders.
