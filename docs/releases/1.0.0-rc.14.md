# AI Usage 1.0.0 RC 14

Release candidate for 1.0.0 fixing a slow window and failed starts on macOS after an update.

- **The window no longer stalls on Keychain access**: the thread that relays every backend reply and event to the window also ran native work inline, including Keychain reads. While a Keychain lookup ran, or waited on its approval prompt, the whole window waited with it. Native calls now run on their own thread.
- **One Keychain read per run**: the vault key is read once and kept in memory, instead of a Keychain round trip for every saved credential.
- **No more "Native operation timed out" after an update**: a macOS Keychain prompt waits for you, but the backend gave up after 30 seconds. The manager then stayed broken until the app restarted. Credential calls now wait up to 10 minutes, and if that runs out the message says what to do.
