# AI Usage 1.0.0

AI Usage brings AI capacity, local usage and shared agent configuration into one desktop control room for Windows and macOS.

## Highlights

- Quota cards with reset countdowns, usage history, model cost estimates and CSV export. Mixed-model sessions expand per model, with token counts deduplicated by API message.
- The tray (Windows) and menu bar (macOS) list the quotas pinned on the Overview, in pinned order, with the same figures as the dashboard.
- One shared library of MCP servers, skills and instructions, synchronized into supported coding clients, with pinned per-device preparation and a native relay and supervisor.
- Clear MCP status: **Running** (a process is alive), **Connected** (a client is attached; the process starts on its next call) and **Ready** (installed, nothing attached), plus actionable states such as Sign-in needed, Reconnect needed, Provider issue, Needs setup and Stopped. Each server has one main action and a menu for the rest.
- A form editor for MCP servers that never silently overwrites another server, keeps fields it does not manage, and syncs agents on save.
- Remote MCP relays return the real reason when a server cannot connect, reconnect expired upstream sessions automatically, and keep sign-ins through temporary provider outages.
- Endpoints using OpenAI-compatible, Anthropic or Ollama protocols, with optional loopback connections, routes, model aliases and client keys.
- Named Google Workspace accounts through the official gws adapter; each request selects its account explicitly.
- Encrypted shared-folder Sharing for endpoints and keys, profiles, MCP definitions, skills, instructions and Google accounts.

## Sign-ins are per device

Remote MCP OAuth sign-ins (for example Cloudflare) stay on the device where you signed in. Providers rotate refresh tokens on every refresh, so a copied sign-in breaks whichever device refreshes second. Sharing carries each server's "connect through AI Usage" setting; sign in once per device. Import never replaces or removes a local sign-in.

## Installation

- Windows x64 installer (per user, unsigned). If AI Usage is started from inside another app's MSIX package (some coding clients are packaged), it relaunches itself as a normal desktop app. A copy installed inside another app's private storage shows a reinstall warning. Launch at login is re-registered at every start.
- macOS Apple Silicon DMG, not notarized. Builds can be signed with a stable local identity (`AIU_MAC_SIGN_IDENTITY`); a self-signed certificate is enough. macOS still asks once per update for access to the saved credentials in Keychain, because without an Apple Team ID it ties "Always Allow" to each build's code hash.
- Hidden relaunches from MCP relays and the CLI never bring the dashboard to the foreground.

## Notes

The Android companion source is included; an Android installer is not part of this release. Automatic updates are not included. Provider availability, permissions and quotas depend on your own installations and accounts. Model prices are estimates. The Claude Code card estimates the 5-hour window from this device's local tokens only. See the README and SECURITY policy for data and credential behavior.
