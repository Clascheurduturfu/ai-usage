# 1.0-beta-3

Mixed-model sessions now expand in Recent sessions and Usage history. Each model shows its own token count, request count, cost and subagent portion, with totals combined across pricing tiers and recorded/estimated groups. Single-model sessions stay compact.

Remote MCP connection details now retain the HTTP status and OAuth error code when a saved refresh grant is rejected. Checks preserve the saved grant, and successful rotation is persisted across restart. Private provider response details and credentials are not displayed. Existing provider quota percentages remain independent of local token counts and API cost estimates.

Reconnect stages a fresh OAuth client registration for this device, avoiding reuse of another device's rotating grant. An existing local sign-in is preserved when importing a newer bundle containing a different registration; newer tokens for the same registration still import. Initial sign-ins still travel through encrypted Sharing. Providers that reject an already-rotated grant need a one-time reconnect. Cancelled or failed authorization leaves the previous saved sign-in intact. To intentionally replace an existing registration from a bundle, sign out locally before importing.
