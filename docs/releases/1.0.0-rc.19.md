# AI Usage 1.0.0 RC 19

Release candidate for 1.0.0 that keeps the Claude Code card signed in and makes the OpenRouter card easier to connect.

- **Claude Code limits no longer need a trip to the terminal**: Claude Code's CLI sign-in lasts a few hours. If you mostly use Claude Code from Claude Desktop, which signs in separately, the CLI's copy expired and the card said to run `claude`. Now, when it has expired, AI Usage asks Claude Code to renew it by running `claude auth status`. Claude Code renews its own sign-in this way, the same as when you open a second terminal, so nothing gets signed out. If the CLI isn't installed, AI Usage uses the copy of Claude Code that ships with Claude Desktop. If the renewal fails, the card says why.
- **Paste an OpenRouter key in AI Usage**: Settings → Plans → OpenRouter key. AI Usage checks the key with OpenRouter before saving it, keeps it encrypted on this device, and includes it in encrypted Sharing so your other devices get it too.
- **ZCode's key is found again**: newer ZCode versions moved their providers to `provider_config.json`, so AI Usage stopped finding the key there, and adding it again in ZCode didn't help. Both the new and the old file are read now. A key saved in AI Usage takes priority.
- **Clearer OpenRouter errors**: a refused key now says it was deleted, disabled or mistyped, and where to replace it, instead of "HTTP 401/401". Spend still shows when only the credit balance can't be read.
