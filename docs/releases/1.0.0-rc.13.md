# AI Usage 1.0.0 RC 13

Release candidate for 1.0.0 with the full Antigravity quota on Windows, model pricing updates and a macOS Dock fix.

## Antigravity quota

- **Every quota group, as Antigravity shows it**: Google's cloud quota endpoint returned only "Claude and GPT models". Antigravity's own panel reads its local language server, which also reports Gemini Models (weekly and 5-hour) and the separate Gemini 4 Argon allowance. Windows now reads that server too, as macOS already did, through `language_server.exe`, its CSRF token and loopback port (`antigravity-rpc.ts`). When Antigravity is closed, Windows uses the cloud endpoint as before.

## Costs

- **New prices**: Claude Fable 5.2 ($8 / $40, cache read $0.20), Fable 5 / 5.1, GPT-6.1 Terra ($1 / $5), Gemini 4 Hydrogen ($1.50 / $7.50), Gemini 4 Carbon ($4 / $20) and Gemini 3.5 Flash ($1.50 / $9).
- **Fixed**: Claude Opus 4.7 and 4.8 matched the Opus 4 / 4.1 rule and were estimated at $15 / $75; they are $5 / $25.
- **Antigravity models by real name**: calls are recorded under the model in Antigravity's display label. For example, `gemini-pro-default` is Gemini 3.1 Pro, `orchestrator-g1-pro` is Gemini 4 Argon, and `gemini-3-flash-a` is Gemini 3.5 Flash, not 3 Flash. The internal id is kept in each event's metadata. Antigravity history re-imports once.
- Costs are computed when shown, so all history uses the new prices.

## macOS

- **Dock icon**: clicking the Dock icon now opens the window. Hiding the Dock icon after the window closes now runs after the window is gone, because changing it during the window's teardown sometimes left a dead icon behind.
