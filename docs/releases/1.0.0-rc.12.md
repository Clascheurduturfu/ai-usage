# AI Usage 1.0.0 RC 12

Release candidate for 1.0.0 with real Antigravity token usage, live Claude limits and correct Gemini quota.

## Antigravity

- **Token usage read straight from Antigravity**: Antigravity 2.x stores each conversation in `~/.gemini/antigravity/conversations/<id>.db`. AI Usage now reads every model call's input, output, thinking and cache-read tokens from its `gen_metadata` rows, and timestamps each call from the step it produced. Before, token usage came only from the Antigravity Token Monitor VS Code extension. That extension now exports empty files, because Antigravity's local `GetAllCascadeTrajectories` returns no conversations. On the test PC, AI Usage had recorded no Antigravity tokens; it now finds 28,630 calls in 258 conversations. The first scan takes about 4 s and later scans take about 70 ms. Extension exports are still read for sessions without a conversation database.
- **Gemini quota no longer disappears when it runs out**: Google's API omits `remainingFraction` when it is 0 (proto3 JSON). An exhausted Gemini model was skipped, so only "Claude and GPT models" showed. A model with a reset time and no fraction now reads as 0%.

## Claude Code

- **Live limits instead of a local guess**: when Claude Code's CLI sign-in is on the device (`~/.claude/.credentials.json`, or the macOS Keychain item `Claude Code-credentials`), the Claude card shows Anthropic's own 5-hour, weekly, Opus and Sonnet windows. These come from `api.anthropic.com/api/oauth/usage`, the numbers behind `/usage`, and include other devices and claude.ai. The token is never refreshed by AI Usage: that would rotate it and sign Claude Code out. Without a CLI sign-in, the card falls back to the local estimate and says why.
