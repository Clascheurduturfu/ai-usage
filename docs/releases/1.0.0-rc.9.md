# AI Usage 1.0.0 RC 9

Release candidate for 1.0.0 fixing Antigravity quota detection across reinstalled Windows machines and Gemini models, unifying compacted MCP token chips, and adding a cross-platform Prepare recipe for Cua Driver.

## Antigravity quotas

- **Windows & cross-install binary discovery**: [antigravityBinaryCandidates()](../../src/main/antigravity-quota.ts) now searches installed Antigravity `language_server` binaries alongside `agy`, and OAuth token refresh iterates through all embedded `GOCSPX-*` secret candidates instead of failing on the first candidate.
- **Gemini quota visibility on Windows and macOS**: Both CloudCode (`fetchAvailableModels`) and running macOS RPC (`GetUserStatus`) Gemini quotas are synthesized into Gemini Pro / Flash / unified buckets when `retrieveUserQuotaSummary` / `RetrieveUserQuotaSummary` omits Gemini and returns only Claude & GPT buckets.

## MCP library & Cua Driver

- **Consistent yellow compacted token chips**: [McpCard](../../src/renderer/src/components/McpCard.tsx) now highlights every compacted MCP token badge in amber (`chip-warn`), regardless of eager schema size.
- **Cua Driver cross-platform Prepare recipe**: [McpPreparation](../../src/main/manager/mcp-preparation.ts) recognizes and prepares `cua-driver` `0.52.0` (`aiUsage.source.kind = "cua-driver"`) across Windows and macOS (reusing existing `cua-driver.exe` / `/Applications/CuaDriver.app`, or downloading and SHA-256-verifying the pinned GitHub Release archive with in-app setup guidance).
