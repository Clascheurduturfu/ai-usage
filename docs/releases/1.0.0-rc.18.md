# AI Usage 1.0.0 RC 18

Release candidate for 1.0.0 that stops Claude Desktop from undoing MCP changes and pausing sync.

- **Claude Desktop's MCP list updates when you quit it**: Claude Desktop keeps its whole settings file in memory and saves it back every few seconds while it runs. A change AI Usage wrote while it was open, such as removing servers you took out of the shared library, was undone moments later. Claude Desktop then kept starting those removed servers and reporting that they "couldn't start". AI Usage now waits while Claude Desktop is open and writes its file as soon as you fully quit it (tray icon → Quit on Windows, Claude → Quit on macOS). Shared library → Sync says when it is waiting.
- **No more "changed outside AI Usage" pause for that**: when a client saves an older copy of its settings that only brings back or drops AI Usage's own relay entries, sync no longer pauses and asks. Those entries are only ever written by AI Usage, so it puts the right list back. A real edit to a shared server's entry still pauses and is explained as before.
