# 1.0-beta-5

## MCP states

- Each server now shows exactly one of three activity states, computed from live counts: **Running** (a process is alive now), **Connected** (a coding client is attached; the process starts on its next tool call) and **Ready** (installed, no client attached). Google Workspace shows Connected while clients are attached, because each Google request runs a short command instead of a resident process. Previously a connected Workspace showed "Running · 0 clients · 0 workers".
- The summary line counts running, connected, ready, attention-needed and stopped servers, and a one-line legend explains the states.

## Editing MCP servers

- A form replaces the raw JSON editor (name, type, command, arguments, environment, URL, headers); the full JSON stays available under "Advanced".
- Adding or renaming a server can no longer silently overwrite another server with the same name.
- Fields the editor does not manage (for example `cwd` or `timeout`) are kept on save.
- A rename keeps the device launch override and the Stopped state.
- Switching a server to a local command, or pointing it at a different URL, removes the old remote sign-in and says so.
- Editing the command of a recipe-installed server explains that Prepare chooses the command on each device.
- Save syncs agents immediately (when automatic sync is on) and reports how many client configurations changed.

## Other

- Claude Code card: with no Claude Code use in the last five hours it shows the full window instead of "Unavailable", and it states that only this device's usage is counted.
- Google project settings: the import button sits on the right, and reads "Replace OAuth client" once one is configured.
