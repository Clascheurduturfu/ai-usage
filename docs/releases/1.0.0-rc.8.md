# AI Usage 1.0.0 RC 8

Release candidate for 1.0.0 fixing macOS backend packaging and polishing the macOS menu bar quota popover.

## macOS menu bar backend & popover fixes

- **Fixed `Backend disconnected` on Homebrew-built macOS bundles**: [scripts/build-broker.mjs](../../scripts/build-broker.mjs) now checks the bundled `aiu-node` Mach-O binary via `otool -L` and downloads/SHA-256-verifies the official standalone `node` binary from `nodejs.org` whenever the host Node links dynamically against Homebrew libraries (such as `@rpath/libnode.*.dylib`).
- **Rounded corners and open/close motion**: The menu bar quota popover window now renders transparently with rounded `16px` corners, subtle elevation shadow, and compositor-based slide/scale/fade entrance and exit animations (respecting `prefers-reduced-motion`).
