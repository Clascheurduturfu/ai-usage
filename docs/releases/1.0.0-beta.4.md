# 1.0-beta-4

## MCP connections

- Coding clients now see the real reason when a remote MCP cannot connect (for example "Token refresh failed: HTTP 400 (invalid_grant). Reconnect cloudflare-bindings…") instead of a bare "Connection closed". The relay no longer closes the client's connection when the upstream fails.
- An expired or dropped upstream session reconnects automatically and retries the request once, so long-running clients keep working after the provider drops the session.
- A token-service outage (HTTP 5xx or a network error) keeps the saved sign-in and is shown as a temporary provider issue instead of "Reconnect required".
- Public servers that advertise prompts (Cloudflare Docs now does) connect again. Servers with stateful capabilities get their own session instead of failing.

## Sharing

- Remote MCP sign-ins are per device. Providers such as Cloudflare rotate the refresh token on every refresh, so a sign-in copied to another device broke whichever device refreshed second. Publish no longer includes these grants; Import never replaces or removes a local sign-in or its "connect through AI Usage" setting, even for older bundles that still contain grants. Sign in once on each device.
- Endpoint keys, Google Workspace accounts, profiles, skills and instructions travel as before.

## Installation (Windows)

- When AI Usage is started from inside another app's MSIX package (Codex, Claude desktop and other packaged clients start it through their MCP relay), it relaunches through Explorer. Windows previously redirected its files into that app's private storage, hiding it from the Start menu.
- A copy installed inside another app's private storage shows a warning with reinstall instructions.

## Shared library

- The MCP list has one status per server (Running, Ready, Idle, Sign-in needed, Reconnect needed, Provider issue, Needs setup, Stopped, Direct), one main action and a menu for the rest. A summary line counts running, ready and attention-needed servers.
- Remote servers no longer show process counters or a sign-in button that does nothing for public servers. Remove asks for confirmation.
- Tabs are labelled MCP servers, Skills, Instructions, Agent sync and Sharing.
