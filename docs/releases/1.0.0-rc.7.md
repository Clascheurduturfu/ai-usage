# AI Usage 1.0.0 RC 7

Release candidate for 1.0.0, building on RC 6 with UI skill organization and cleanup controls.

## Skill folders (UI grouping)

- **Shared library → Skills** now lets you create folders to group related skills (for example **AWS**, **Cloudflare**, or custom workflow packs).
- Folder membership is stored in `manager.json` (and travels with encrypted Sharing) while keeping files flat inside `~/.agents/skills` and `~/.agents/skills-disabled` so every coding agent still discovers enabled skills automatically.
- Collapse or expand folders individually (remembered locally), filter across both skills and folder names, drag and drop skill cards between folders and **Ungrouped**, move skills via the row menu, batch-toggle every skill in a folder with one switch, or manage folder membership in bulk with live filtering.

## Delete skills from the library

- Each skill row now includes a delete button paired with a confirmation dialog.
- Confirming deletes the skill directory from `skills` / `skills-disabled` (or unlinks a symlinked skill without touching its target), removes references from agent profiles and skill folders, and syncs connected coding agents.
- Syncing after deleting or disabling a skill now prunes leftover empty subdirectories bottom-up inside managed agent skill targets (such as `~/.claude/skills` and `~/.gemini/config/skills`) while preserving symlinks and unrelated native skill folders.

## Sync fixes

- When both Gemini CLI and Antigravity share `~/.gemini/GEMINI.md`, syncing now writes a single marked `<!-- AI Usage shared instructions -->` block cleanly across repeated syncs instead of alternating between raw and marked formats and duplicating the file.
