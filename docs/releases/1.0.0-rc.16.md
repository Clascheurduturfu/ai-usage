# AI Usage 1.0.0 RC 16

Release candidate for 1.0.0 that checks your Google sign-ins and brings the window back from the taskbar.

- **Google account sign-ins are actually checked**: the google-workspace connection check, and a new Check sign-ins button next to your Google accounts, renew each account's sign-in and read which permissions Google granted. Each account now shows Signed in, Missing permissions (with the missing ones named, for example Gmail read and organize), Needs reconnect (Google revoked or expired the sign-in), or Check failed, instead of a plain "Saved sign-in". Agents see the same states through workspace_accounts.
- **Clear errors instead of "gws failed"**: a failed Workspace call now says what Google refused and why, for example a sign-in Google rejected (HTTP 401) or a permission the account never granted (HTTP 403), with what to do next. Previously gws's own explanation was dropped.
- **Clicking the tray icon restores a minimized window** on Windows and brings it to the front. Before, it did nothing while the window sat minimized in the taskbar.
