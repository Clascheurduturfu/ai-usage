# 1.0-rc-1

## No more unexpected windows

The dashboard no longer jumps to the foreground on its own. When a coding client's MCP relay or the CLI cannot reach AI Usage (for example after a dropped connection or while the app restarts), it relaunches AI Usage with `--hidden`. That second launch used to open the dashboard every time. Now a second launch shows the window only when you open the app yourself; hidden relaunches, including ones routed through Explorer on Windows, stay in the background.

## Pinned quotas in the menu bar and tray

The menu bar (macOS) and tray (Windows) menus list the quotas pinned on the Overview, in pinned order, using the same figures as the dashboard: ChatGPT / Codex windows, Antigravity's tightest limit, OpenRouter's remaining monthly allowance and the Claude Code 5-hour estimate. Pinning or unpinning updates the menu, which is only rebuilt when a line changes. The macOS capacity popover shows the same pinned cards.

## macOS signing

Mac builds can be signed with a stable local identity (`AIU_MAC_SIGN_IDENTITY`, optionally `AIU_MAC_SIGN_KEYCHAIN`); a self-signed code-signing certificate is enough. Correction made after release: this does not stop the Keychain prompt after an update. Without an Apple Team ID, macOS records "Always Allow" against each build's code hash (`cdhash` partition), so one approval per update remains. Builds without an identity stay ad-hoc signed.
