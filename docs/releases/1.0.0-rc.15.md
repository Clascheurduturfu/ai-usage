# AI Usage 1.0.0 RC 15

Release candidate for 1.0.0 that cleans up MCP servers left behind in client configs after they were removed from the shared library.

- **Removed servers no longer linger in your clients**: when an MCP server leaves the shared library, sync deletes it from every client's config. Sync remembers which server names it wrote, but it replaced that list with the current library after every write, even when a client's file had not been written: a file you chose to leave as it is, a file that could not be read at that moment, or a library that changed between the review and the write. The servers that file still listed were then treated as your own and never removed. Sync now keeps tracking a removed name until every client that lists it has actually been rewritten.
- **Existing leftovers are cleaned up**: entries that launch AI Usage's own relay are always treated as AI Usage's, so the next sync removes the ones whose server no longer exists. The review lists each one as "Removes MCP server …".
- **A clear message for a removed server**: a client that still starts a removed server through the relay now hears that the server was removed from the shared library and that syncing removes it, instead of "not set to connect through AI Usage on this device".
