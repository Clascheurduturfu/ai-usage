# AI Usage 1.0.0 RC 20

Release candidate for 1.0.0 that adds four coding tools, reads Mistral Vibe's real token counts, and shows each tool's CLI and desktop app as one.

- **One card per tool, whatever you run it in**: a tool's CLI, desktop app and editor extension share one settings folder and one usage log, so AI Usage counts and syncs them once. Each card on Connected tools and Agent profiles now lists those parts, with a check on the ones this device has.
- **Mistral Vibe, CLI and the new Vibe desktop app**:
  - **Token counts**: Vibe 3 moved its sessions to a new format, so AI Usage no longer found them and only counted messages. It now reads each session's token total, shared by the CLI and the desktop app. Vibe keeps a running total rather than one entry per request, so each scan records how much a session grew since the last one.
  - **Shared library**: Vibe now gets the shared library: MCP servers in `~/.vibe/config.toml`, skill exclusions in `disabled_skills`, and the shared instructions in `~/.vibe/AGENTS.md`. It already reads the shared skill folder on its own.
- **Cursor usage**: Cursor keeps no usable token counts on disk, so AI Usage reads your account's usage export with the editor's own sign-in, the same per-request list Cursor's dashboard downloads. It is refreshed with the live quotas. MCP entries for Cursor now carry the `type` field Cursor requires.
- **Kimi Code** (CLI, desktop app, VS Code extension): tokens per model request from `~/.kimi-code/sessions`, and MCP servers in `~/.kimi-code/mcp.json`. Kimi Code already reads the shared skills and the shared AGENTS.md itself.
- **DeepSeek Harness** (`dsh` CLI and desktop app): tokens per model call from its compressed session logs. MCP servers go in a marked block of `~/.dsh/cordis.patch.yml`; your own rows in that file are left alone. It already reads the shared skills and AGENTS.md itself.
- **pi**: tokens and cost per model call from `~/.pi/agent/sessions`, MCP servers in `~/.pi/agent/mcp.json`, and the shared instructions in `~/.pi/agent/AGENTS.md`. Forked sessions are not counted twice.
- **Gemini 4 Argon removed from the Antigravity card**: Google retired Argon's separate allowance. AI Usage no longer shows it, whether Antigravity reports it or the card had kept its last value, and the card no longer suggests opening Antigravity to see it. Past Argon usage and its pricing stay in your history.
- **Claude Code sign-in on macOS**: `claude auth status` does not renew the sign-in on macOS. When it has expired, AI Usage now starts Claude Code in a hidden terminal for a few seconds, the same as running `claude`, and closes it once the sign-in is renewed. No prompt is sent, so it uses none of your quota.
